# Laiba Birthday Website

## Files
- `index.html` — website content and sections
- `style.css` — design and responsive styling
- `script.js` — navigation, cake cutting, balloon release, confetti and music toggle
- `images/` — the two supplied gallery pictures

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example `laiba-birthday`).
2. Upload all files and folders in this project (not just the ZIP).
3. Open repository **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then Save.
6. Wait for the Pages URL to appear.

The music toggle plays a small synthesized celebratory melody after the visitor taps it; no external music file is required.

Note: This is a custom first version based on the requested sections and interactions. The supplied reference website could not be fetched for a pixel-by-pixel inspection in this session, so exact visual matching is not guaranteed.
